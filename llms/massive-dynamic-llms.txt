# Massive Dynamic

> Massive Dynamic (massive-dynamic.ai) is a Paris-based AI company that bills itself as "The Advertising Copilot" and "the human-AI interface for massive scale." It gives media and advertising teams an AI Analysis Copilot (daily checks, QBR preparation, Media Mix Modeling) and Execution Delegation, where an agent handles operational campaign setup, working inside the Slack and email workflows operators already use. Founded in 2025 by Trystan Chabert (ex-Voodoo) and Guillaume le Roy (ex-Qonto), it raised a ~EUR 3M pre-seed led by Seedcamp in July 2025. As of 2026-08-12 Massive Dynamic publishes NO public API, NO developer documentation, NO SDKs and NO machine-readable contract of any kind — this file is generated by API Evangelist from the public company profile, not published by the company.

## What this company sells

- AI Analysis Copilot — partner with AI to run daily campaign checks, prepare a quarterly business review, or implement Media Mix Modeling.
- Execution Delegation — an agent handles operational details such as campaign setup while operators set high-level direction.
- Delivery surface — Slack and email; the product is described as "a modular conduit between strategy and activation teams."
- Data governance — each advertiser's data is ring-fenced and can be stored in a separate secure cloud; the company states it does not use customer data to train or improve models.
- Deployment guidance — hands-on support for implementation, training, and change management.
